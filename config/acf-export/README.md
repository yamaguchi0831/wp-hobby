# ACF設定バックアップ

このディレクトリには、WordPress管理画面のACFツールから書き出した一括エクスポートJSONを保管します。

## 収録ファイル

- `acf-export-2026-09-14.json`: フィールドグループ5件、タクソノミー2件、カスタム投稿タイプ4件

## 復元方法

WordPress管理画面の「ACF → ツール → JSONからフィールドグループをインポート」から対象ファイルを読み込みます。

このファイルは一括エクスポートの原本です。ACF Local JSON用の個別ファイルではないため、そのままテーマの`acf-json`ディレクトリへ配置しません。Local JSONを導入する場合は、インポート後に各設定を保存し直して個別JSONを生成します。
