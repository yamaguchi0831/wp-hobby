# 第1段階テーマ化 検証状況

更新日: 2026-08-04

## 完了

- クラシックテーマの基本ファイルを作成
- `wp_head()`、`wp_body_open()`、`wp_footer()`を実装
- `language_attributes()`、`body_class()`、タイトルサポートを実装
- CSSとJavaScriptをenqueue
- ヘッダーとフッターをPHP出力へ移行
- 静的コンポーネントをテンプレートパーツへ移行
- 15種類の静的参照画面をPHPテンプレートへ移行
- PHPファイルからインラインCSS・JavaScriptを除去
- `include-components.js` と `[data-hb-include]` の依存を除去
- テーマ内アセットを `get_theme_file_uri()` で参照
- PHP構文検査を実施
- 汎用ページ、アーカイブ、検索、404の空状態を実装
- 通常投稿のお知らせ一覧・詳細をWordPress標準データへ接続
- コラム一覧・詳細を `column` の投稿データへ接続
- コラムの新着、ACF選定の人気記事、`genre`、`column-tag` を共通サイドバーへ接続
- コラム詳細の関連記事と `genre` リンクカードを動的化
- コラムのアイキャッチ未設定時に表示するno-image画像を実装
- 取り扱い品目、お客様の声、買取実績、買取価格表をWordPressデータへ接続
- 買取実績カード、関連実績、ジャンルフィルター、段階表示を共通パーツとして実装
- `purchase-record` 一覧・詳細と `genre` アーカイブをDBへ接続
- `purchase-price` をジャンル、表示順、表示件数、価格、強化中表示へ接続
- お問い合わせフォームの送信、検証、送信制限、自動返信、リダイレクトを実装
- お問い合わせの送信先とメール文面をテーマ設定画面から編集可能化
- 買取方法ページのリード画像をテーマアセットへ差し替え

## Localで確認済み

- コラム一覧・詳細の表示
- コラムの新着、人気、カテゴリ、タグと各リンク
- コラム詳細の関連記事
- 確認したコラム画面でブラウザコンソールエラーがないこと

## Localで確認予定

- PC・モバイルの静的HTMLとの表示比較
- CSS・JavaScript・画像の404
- コラム以外の主要画面のブラウザコンソールエラー
- FAQ、タブ、フォームUIの操作
- キーボード操作とフォーカス表示
- `WP_DEBUG`、PHP Warning、Notice、Deprecated
- WordPress管理バー表示時のレイアウト
- 投稿・ターム・ACFが未設定、1件、多数の場合の表示
- アイキャッチ未設定時のno-image表示
- お知らせとコラムのページネーション
- 買取実績フィルターの全件・ジャンル別表示、初期8件、「もっと見る」
- 買取実績が0件・1件・多数件、ジャンル未設定・複数設定の場合の表示
- 価格表が0件・10件以下・11件以上、片側価格未入力・両価格未入力の場合の表示
- SMTP設定後の管理者宛・入力者宛メール、送信制限、303リダイレクト
- 買取方法ページのリード画像がPC・モバイルで崩れないこと
