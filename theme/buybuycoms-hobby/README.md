# バイバイコムズ ホビー買取テーマ

静的参照データをWordPressクラシックテーマへ移植した、第1段階のテーマです。

## 現在の実装範囲

- `pages/*.html` の15画面をWordPressテンプレートへ移植
- `components/*.html` をヘッダー、フッター、テンプレートパーツへ移植
- `[data-hb-include]` と `include-components.js` への依存を廃止
- インラインCSSを `asset/css/page-static.css` へ移動
- インラインJavaScriptを `asset/js/pages/` へ移動
- WordPress標準のテーマサポート、メニュー、カスタムロゴ、エディターCSSを登録
- 検索、404、汎用固定ページ、アーカイブのフォールバックを実装
- 通常投稿のお知らせ一覧・詳細をWordPress標準データへ接続
- `column` の一覧・詳細・関連記事・新着記事を投稿データへ接続
- `genre`、`column-tag`、ACF選定の人気記事をコラム共通サイドバーへ接続
- コラムのアイキャッチ未設定時にno-image画像を表示

固定ページと一部の共通パーツには静的HTML由来の固定表示が残っています。
通常投稿とコラムはWordPressデータへ接続済みです。CPT、カスタムタクソノミー、
ACF等の登録主体と運用手順、フォーム送信処理はテーマ外の構成を含めて整理が必要です。

## Localへの配置

`theme/buybuycoms-hobby/` を、Localサイトの次のディレクトリへ配置します。

```text
app/public/wp-content/themes/buybuycoms-hobby/
```

WordPress管理画面の「外観 → テーマ」から有効化してください。

## 固定ページ

次のslugで固定ページを作成します。本文は第1段階の専用テンプレートでは
使用しません。

| ページ | slug |
|---|---|
| 買取方法 | `flow` |
| カテゴリー一覧 | `genre-list` |
| よくある質問 | `faq` |
| 会社概要 | `company` |
| 選ばれる理由 | `reason` |
| 査定フォーム | `contact` |
| プライバシーポリシー | `privacy` |

トップ用の固定ページを作成し、「設定 → 表示設定」でホームページに指定します。
お知らせ一覧用ページは `info` を想定しています。

## データ連携

- 通常投稿: お知らせ一覧・詳細のタイトル、本文、抜粋、日付、カテゴリー、アイキャッチ
- `column`: 一覧・詳細、新着、人気、関連記事、抜粋、アイキャッチ
- `genre`: コラムの分類、一覧・詳細からのタームリンク、詳細下のリンクカード
- `column-tag`: コラムサイドバーのタグ一覧
- ACF: `column-featured`、`column-featured-order`、`genre-text-for-card`

## 次段階で確定・文書化する項目

- `purchase-record` と `column` の登録主体
- `genre` と `column-tag` の登録主体と紐付け対象
- ACFフィールドグループの定義、必須／任意、未入力時の表示
- メインビジュアル画像の管理方法と未設定時のフォールバック
- 買取実績テーブルのデータ構造
- フォームを担当するプラグインまたは外部サービス
- 電話番号、営業時間、LINE URL等の管理場所
- 対応するWordPress・PHP・ブラウザの最低バージョン

## 既知の制限

- 固定ページと一部の共通パーツは固定表示です。
- CPT、タクソノミー、ACFの登録コードはこのテーマ内にありません。現在のWordPress環境側の登録方法を運用資料へ記録する必要があります。
- 買取実績一覧・詳細と `genre` アーカイブは、DB接続状況と境界値表示の確認が残っています。
- フォーム画面はUI確認用で、送信処理は行いません。
- LINEリンクなど、リンク先未確定の導線は暫定的にサイト内ページへ向けています。
- `placehold.co` の仮画像が残っています。
- コラム一覧・詳細の基本表示とリンク、関連記事、コンソールエラーなしはLocalで確認済みです。
- 空データ、アイキャッチ未設定、ページネーション、モバイル、管理画面操作、`WP_DEBUG`の網羅確認は未完了です。
