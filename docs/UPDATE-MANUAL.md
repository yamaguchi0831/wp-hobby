# 売買コムズ Hobbyベース 更新担当者向けマニュアル

このマニュアルは、WordPress管理画面からサイトを更新する人向けの運用手順です。コードを触らずに更新できる範囲、独自機能の表示条件、並び順、オリジナルブロックの使い方をまとめています。

## 1. 最初に知っておくこと

このテーマでは、ページの多くが「投稿データ」「ジャンル」「カスタム項目」を組み合わせて自動表示されます。

更新時は、次の考え方で操作してください。

| 更新したい内容 | 主に触る場所 |
|---|---|
| お知らせ | 投稿 |
| コラム記事 | コラム |
| 買取実績カード | 買取実績 |
| 買取価格相場 | 買取相場、または買取価格CSV |
| 取り扱いジャンルページ | 取り扱いジャンル |
| お客様の声 | お客様の声 |
| 査定フォームのメール文面 | 問合せフォーム |
| ヘッダーメニュー | 外観 → メニュー |

固定ページの本文は、現在の専用テンプレートでは基本的に使いません。たとえば「買取方法」「よくある質問」「会社概要」などは、固定ページを作ることでURLとテンプレートを有効にしますが、本文欄を編集しても表示に反映されない箇所があります。

## 2. 固定ページとURL

以下の固定ページは、指定のスラッグで作成しておきます。スラッグが違うと、リンクや専用デザインが想定どおり動かないことがあります。

| ページ名 | スラッグ | 備考 |
|---|---|---|
| 買取方法 | `flow` | 専用テンプレート |
| カテゴリー一覧 | `genre-list` | 取り扱いジャンル一覧 |
| よくある質問 | `faq` | 専用FAQページ |
| 会社概要 | `company` | 会社情報ページ |
| 選ばれる理由 | `reason` | 理由紹介ページ |
| 査定フォーム | `contact` | フォームページ。スマホ固定CTAは非表示 |
| 送信完了 | `thanks` | フォーム送信後の遷移先 |
| プライバシーポリシー | `privacy` | プライバシーページ |
| お知らせ一覧 | `info` | 「設定 → 表示設定」の投稿ページに指定 |

トップページ用の固定ページを作成し、「設定 → 表示設定」でホームページに指定します。

## 3. 共通の公開ルール

### 公開状態

一覧やカードに出すには、対象データを「公開」にしてください。下書き、非公開、レビュー待ちは基本的にフロント画面へ出ません。

### 画像がない場合

一部の表示には代替画像や空の画像枠があります。

| 場所 | 画像未設定時 |
|---|---|
| コラム一覧・関連記事・サイドバー | no-image画像を表示 |
| お客様の声 | デフォルトの人物アイコンを表示 |
| 取り扱いジャンルカード | 空の画像枠を表示 |
| 買取実績カード | 空の画像枠を表示 |
| ジャンル詳細のヒーロー画像 | テーマ内の既定画像を表示 |

画像はできるだけ横長または4:3に近い比率を使うと崩れにくくなります。

## 4. ヘッダー・メニュー

ヘッダーの主要メニューは「外観 → メニュー」で設定します。PC表示とスマホのドロワーメニューで同じメニューを使います。

推奨の並び順は次のとおりです。

1. 買取方法
2. 選ばれる理由
3. 買取品目一覧
4. コラム
5. よくある質問
6. 会社概要

メニューが未設定の場合も、テーマ側で上記に近い初期メニューを表示します。ただし、運用時は管理画面から正式なメニューを割り当てることをおすすめします。

「カテゴリー一覧」というメニュー名を使っている場合、テーマ側で「買取品目一覧」と表示されます。

## 5. 取り扱いジャンル

管理画面の「取り扱いジャンル」で、ジャンル別ページや一覧カードの内容を管理します。

### 主な入力項目

| 項目 | 表示される場所 | 入力の目安 |
|---|---|---|
| 名前 | ジャンル名、見出し、リンク名 | 例: フィギュア |
| スラッグ | URL | 半角英数字推奨 |
| 一覧用サムネイル | カテゴリー一覧、トップ等のジャンルカード | 商品群が分かる画像 |
| 一覧説明用ショートテキスト | ジャンルカード下部 | 短めの説明文 |
| ヒーロー画像 | ジャンル詳細ページの上部 | 大きく見せる代表画像 |
| FVメインテキスト | ジャンル詳細ページのヒーロー | 例: 未開封も、箱なしも |
| サブテキスト1・2 | ヒーロー下の補足 | 1行ずつ短く |
| バッジ内テキスト | ヒーロー内の強調バッジ | 改行可 |
| 人気カテゴリフラグ | ジャンルカードの「強化中」表示 | ONでバッジ表示 |
| よくある質問 | ジャンル詳細ページ下部 | JSON形式で入力 |
| カテゴリ表示順 | ジャンルカードや価格表の並び順 | 数字が小さいほど先 |
| 相場テーブルフラグ | 価格表への表示可否 | ONで対象にする |
| 相場テーブル表示アイテム数 | トップ等の価格表表示件数 | 空なら10件、0なら非表示 |

### 並び順

ジャンルの並び順は「カテゴリ表示順」で決まります。数字が小さいものから先に出ます。未入力のジャンルは、入力済みジャンルの後ろに回り、名前順で並びます。

### ジャンルFAQの入力形式

「よくある質問」は、次のような形式で入力します。

```json
[
  {
    "question": "箱なしでも買取できますか？",
    "answer": "買取可能です。状態や付属品の有無を確認して査定します。"
  },
  {
    "question": "事前査定はできますか？",
    "answer": "LINEまたはフォームから写真を送っていただけます。"
  }
]
```

質問または回答が空のものは表示されません。6件以上ある場合、最初は5件だけ表示され、「もっと見る」ボタンで残りを表示します。

## 6. 買取実績

管理画面の「買取実績」で、実際の買取事例を登録します。

### 主な入力項目

| 項目 | 表示される場所 | 備考 |
|---|---|---|
| タイトル | カードタイトル、詳細ページタイトル | 商品名やまとめ売り内容 |
| 本文 | 詳細ページ本文 | 詳細説明 |
| アイキャッチ画像 | 詳細ページ等 | 必要に応じて設定 |
| 写真 | 買取実績カード画像 | カードで主に使われる画像 |
| 買取価格 | カード、ブロック候補 | 数字だけでも「円」付きでも可 |
| 買取方法 | 詳細情報 | 選択式 |
| 事例タグ | 詳細情報 | 選択式 |
| 抜粋 | カード本文 | 短く入力 |
| 買取日 | カード日付 | 未入力時は投稿日 |
| 都道府県 | カード本文 | 「○○で買取」と表示 |
| JANコード | 詳細情報 | 必要な場合のみ |
| 推奨買取方法 | 詳細情報 | 必要な場合のみ |
| 買取強化フラグ | 強化表示用 | 現在の表示箇所に注意 |
| 取り扱いジャンル | 絞り込み、関連表示 | 必ず設定推奨 |

### 表示ルール

買取実績カードは、基本的に公開日が新しい順に表示されます。

ジャンル詳細ページでは、そのジャンルに紐づく買取実績だけが表示されます。コラム内の「買取実績（コラム用）」ブロックでも、コラムと同じジャンルの実績が自動補完されます。

価格が空の場合、カードの価格表示は出ません。価格表とは別データなので、買取実績を登録しても買取相場には自動追加されません。

## 7. 買取相場・価格表

管理画面の「買取相場」で、価格表に出す商品名と価格を管理します。

### 主な入力項目

| 項目 | 表示される場所 | 備考 |
|---|---|---|
| タイトル | 価格表の商品名 | CSVでも照合に使うため安易に変更しない |
| 取り扱いジャンル | 価格表の分類 | 価格表表示に必須 |
| 買取強化フラグ | 「買取強化中」表示 | ONでラベル表示 |
| 下限金額 | 価格表示 | 半角数字推奨 |
| 上限金額 | 価格表示 | 半角数字推奨 |

### 価格表示

下限・上限の両方が空の場合は `ASK` と表示されます。  
片方だけ入力した場合は、入力された側だけを使って `～` を含む表示になります。通常は下限と上限を両方入れるか、両方空にしてください。

### 表示条件

価格表に出すには、次の条件が必要です。

1. 買取相場の投稿が公開されている
2. 取り扱いジャンルが設定されている
3. ジャンル側の「相場テーブルフラグ」がONになっている
4. ジャンル側の「相場テーブル表示アイテム数」が0ではない

ジャンル詳細ページでは、そのジャンルの買取相場をすべて表示します。最初は10件まで表示され、必要に応じて「もっと見る」が出ます。

トップや共通価格表では、ジャンルごとに「相場テーブル表示アイテム数」で件数を調整できます。空欄なら10件、0ならそのジャンルを出しません。

### CSV一括更新

管理画面の「買取価格CSV」から、価格表をCSVで一括更新できます。

基本手順は次のとおりです。

1. 「CSVをダウンロード」を押す
2. ダウンロードしたCSVをExcel等で編集する
3. 「アップロードして検証」を押す
4. エラーがなければ内容を確認する
5. 「検証済みデータをDBへ反映」を押す

CSVの列は固定です。

```text
post_id,title,genre,product-buying-flag,product-min-price,product-max-price
```

既存データを更新する場合、変更してよいのは原則として次の3列です。

- `product-buying-flag`
- `product-min-price`
- `product-max-price`

`post_id`、`title`、`genre` は照合用です。既存行では変更しないでください。

新規作成する場合は、行を追加して `post_id` を空欄にします。`title`、既存の `genre`、フラグ、価格を入力してください。複数ジャンルは ` | ` で区切ります。新規作成された買取相場は公開状態になります。

価格は50円以上10,000,000円以下です。空欄はASK扱いです。CSV内に1件でもエラーがあると、データベースには反映されません。

## 8. コラム

管理画面の「コラム」で記事を作成します。

### 基本入力

| 項目 | 表示される場所 | 備考 |
|---|---|---|
| タイトル | 一覧・詳細 | 記事タイトル |
| 本文 | 詳細ページ本文 | ブロックエディターで編集 |
| 抜粋 | コラム一覧カード | 未入力なら説明文は非表示 |
| アイキャッチ画像 | 一覧、詳細、関連記事、サイドバー | 未設定時はno-image |
| 取り扱いジャンル | ラベル、関連記事、内部リンクカード、ブロック自動取得 | 設定推奨 |
| コラムタグ | サイドバーのタグ一覧 | 必要に応じて設定 |
| おすすめに表示フラグ | 人気記事 | ONで候補 |
| おすすめコラム順位 | 人気記事の並び順 | 数字が小さいほど先 |

### コラム一覧

コラム一覧は1ページ10件表示です。公開日が新しい順に並びます。

カードには、先頭の取り扱いジャンル、タイトル、抜粋、公開日が表示されます。抜粋が空の場合、本文から自動生成されず、説明文は表示されません。

### コラム詳細

詳細ページには、設定されたジャンル名、更新日、アイキャッチ、本文が表示されます。本文の最後には、先頭ジャンルへの内部リンクカードが自動表示されます。

関連記事は、同じジャンルが設定された他の公開コラムから最大3件、ランダムで表示されます。対象がなければ関連記事セクションは表示されません。

### サイドバー

コラム一覧・コラム詳細のサイドバーには、次のブロックが表示されます。

| ブロック | 条件 | 並び順 |
|---|---|---|
| 新着記事 | 公開コラムがある | 新しい順、最大3件 |
| 人気記事 | おすすめフラグONの公開コラムがある | おすすめ順位の小さい順、同順位は新しい順、最大3件 |
| カテゴリ | 公開コラムに紐づくジャンルがある | 名前順 |
| タグ | 公開コラムに紐づくタグがある | 名前順 |

## 9. コラム用オリジナルブロック

コラム本文では、テーマ独自のブロックを使えます。ブロック挿入メニューで探してください。

### 買取方法（コラム用）

3つの買取方法カードを本文内に表示します。

このブロックでは、見出し「あなたに合わせて選べる、3つの買取方法」は表示されません。コラム本文内で見出しが重複しないようにするためです。

カード名は見た目上は見出しのように見えますが、本文の見出し階層には影響しません。

### 買取実績（コラム用）

コラムに関連する買取実績カードを最大6件表示します。

表示ルールは次のとおりです。

1. ブロック設定で個別指定した買取実績を先に表示
2. 6件未満の場合、コラムと同じジャンルの新着買取実績で補完
3. 表示対象がない場合は「実績がありません」と表示

見出しは、コラムに設定された先頭ジャンル名を使って「○○の買取価格表」と表示されます。ジャンル未設定時は「買取価格表」です。

ブロック右側の設定パネルから、タイトル検索で買取実績を選べます。候補にはタイトルと買取価格が表示されます。

### 内部リンクカード

コラム本文内に、ジャンルまたはコラムへのリンクカードを挿入できます。

選べるリンク先は次の2種類です。

| 種類 | 表示内容 |
|---|---|
| 取り扱いジャンル | ジャンル名、ヒーロー画像、ショートテキスト |
| コラム | コラムタイトル、アイキャッチ、SEO説明文 |

ジャンル画像が未設定の場合は仮画像が出ます。コラム側の説明文は、SEOプラグインの説明文がある場合に使われます。

## 10. お客様の声

管理画面の「お客様の声」でレビューを登録します。

### 主な入力項目

| 項目 | 表示される場所 | 備考 |
|---|---|---|
| タイトル | お客様名として表示 | 例: 大阪府 A様 |
| 本文 | レビュー本文 | 空なら本文部分は非表示 |
| アイキャッチ画像 | 顔写真・アイコン | 未設定時はデフォルト画像 |
| 星の数 | 星表示 | 0から5 |
| 年齢 | プロフィール | 任意 |
| 職業 | プロフィール | 任意 |
| 取り扱いジャンル | ジャンル別表示 | 設定推奨 |

お客様の声は最大3件、新しい順に表示されます。ジャンル詳細ページやジャンルに紐づく詳細ページでは、同じジャンルのお客様の声だけが表示されます。該当レビューがない場合、セクションごと非表示になります。

## 11. お知らせ

通常の「投稿」はお知らせとして使います。

お知らせ一覧には、通常投稿のタイトル、本文、抜粋、日付、カテゴリー、アイキャッチが反映されます。「設定 → 表示設定」で投稿ページを `info` に指定してください。

## 12. 問合せフォーム

管理画面の「問合せフォーム」で、フォーム送信先やメール文面を編集できます。

### 設定できる項目

| 項目 | 内容 |
|---|---|
| メールの送信先 | 管理者宛メールの宛先 |
| 管理者宛メールの件名 | 管理者に届くメール件名 |
| 管理者宛メールの共通本文 | すべての買取方法で共通の本文 |
| お申込内容の文面 | 宅配・出張・店頭など買取方法別の差し込み文 |
| 入力者宛メールの送信者名 | 自動返信メールの差出人名 |
| 入力者宛メールの件名 | 自動返信メール件名 |
| 入力者宛メールの本文 | 自動返信メール本文 |
| 送信後のリダイレクトページ | 送信後に移動するページ |

メール文面では、画面に表示されているメールタグを使えます。たとえば `[customer-name]` はお客様名、`[detail]` は買取方法別の申込内容、`[request-number]` は依頼番号に置き換わります。

`[detail]` は、宅配のダンボール必要・不要、出張買取、店頭買取で文面が切り替わります。管理者宛メールの共通本文から消すと、買取方法別の詳細が届かなくなるので注意してください。

### フォームの主な制限

- 宅配買取は「10点以上」が前提です。
- 宅配で買取キット希望の場合、段ボールはS/M/L/LLそれぞれ最大5枚までです。
- 出張買取は第1希望日の入力が必須です。
- 電話番号は0から始まる10桁または11桁です。
- 郵便番号は7桁です。
- 同じIPから短時間に送信しすぎると制限されます。

## 13. スマホ固定CTA

スマホ表示では、画面下部に「WEB査定」「LINE査定」の固定CTAが表示されます。

ただし、査定フォームページでは固定CTAは表示されません。フォーム入力中に画面下部を邪魔しないためです。

## 14. 表示されないときの確認リスト

何かが表示されない場合は、次を順番に確認してください。

1. 対象データが公開状態になっているか
2. 必要なジャンルが設定されているか
3. ジャンル側の表示フラグがONになっているか
4. 表示件数が0になっていないか
5. 画像や抜粋など、表示に必要な項目が空ではないか
6. 固定ページのスラッグが正しいか
7. メニューが正しい場所に割り当てられているか
8. CSV更新の場合、検証後に「DBへ反映」まで押したか

## 15. 更新前後のおすすめ確認

公開前後に、最低限次の画面を確認してください。

| 更新内容 | 確認する画面 |
|---|---|
| ジャンルを追加・変更 | カテゴリー一覧、ジャンル詳細、ヘッダー/フッターのジャンルリンク |
| 買取実績を追加 | 買取実績一覧、該当ジャンル詳細、関連コラム内ブロック |
| 買取相場を更新 | ジャンル詳細の価格表、トップ等の共通価格表 |
| コラムを追加 | コラム一覧、コラム詳細、サイドバー、関連記事 |
| お客様の声を追加 | トップ、ジャンル詳細、買取実績関連ページ |
| フォーム文面を変更 | テスト送信、管理者宛メール、自動返信メール |
| メニューを変更 | PCヘッダー、スマホメニュー |

PCとスマホの両方で確認してください。特にコラム本文、価格表、フォームはスマホで横にはみ出していないかを見るのがおすすめです。
